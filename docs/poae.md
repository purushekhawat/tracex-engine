# TRACE-X Proof-of-Attribution Engine (PoAE) Methodology
## Explainable Cross-Chain VASP Attribution Scoring Framework

> **SIH 26182 — Operational Intelligence Specification**  
> **Target Audience**: Law Enforcement Agencies (LEAs), Cyber Crime Investigators, Forensic Analysts, and Judicial Auditors.

---

## ⚖️ 1. Fundamental Legal & Attribution Principles

1. **Proximity Is NOT Ownership**: TRACE-X **never** claims a suspect wallet is directly owned or operated by a Virtual Asset Service Provider (VASP) simply because transaction flows connect them.
2. **Strict Categorization Tiers**:
   - **`VERIFIED_LABEL`**: Official, documented deposit or withdrawal infrastructure directly owned by the VASP.
   - **`STRONG_ASSOCIATION`**: Direct 1–2 hop high-volume flow to a verified VASP deposit wallet with strong temporal and flow continuity.
   - **`INFERRED_ASSOCIATION`**: Multi-hop path ($\le N$ hops) matching known deposit behavior, peel chain structures, or intermediary pass-throughs.
   - **`UNKNOWN`**: Unlabeled address or decentralized contract without conclusive intelligence indicators.
3. **Full Legal Explainability**: Every score generated by PoAE is accompanied by a breakdown of candidate VASP, evidence score (0–100), confidence basis reasons, path transaction hashes, and explicit uncertainty factors.

---

## 📊 2. Proof-of-Attribution Multi-Factor Feature Breakdown

PoAE evaluates 8 independent evidence features for every candidate VASP destination:

$$S = \max\left(0, \min\left(100, F_{\text{label}} + F_{\text{path}} + F_{\text{flow}} + F_{\text{temp}} + F_{\text{recurrence}} + F_{\text{cluster}} + F_{\text{cross\_chain}} - P_{\text{ambiguity}}\right)\right)$$

### Feature Weights & Scoring Rules:

| Feature | Score Range | Description & Scoring Criterion |
| :--- | :--- | :--- |
| **1. Address Label Strength ($F_{\text{label}}$)** | `0 - 30 pts` | `30 pts` for official `VERIFIED` label; `20 pts` for `STRONG_ASSOCIATION` tag; `10 pts` for `INFERRED` label; `0 pts` for `UNKNOWN`. |
| **2. Path Hop Distance ($F_{\text{path}}$)** | `0 - 20 pts` | `20 pts` for 1-hop direct transfer; `15 pts` for 2-hops; `10 pts` for 3-hops; `5 pts` for 4-hops; `0 pts` for $>4$ hops. |
| **3. Value-Flow Continuity ($F_{\text{flow}}$)** | `0 - 20 pts` | `20 * (Value Reached Target / Initial Value Sent)`. High value retention indicates purposeful fund routing rather than random dispersion. |
| **4. Temporal Proximity ($F_{\text{temp}}$)** | `0 - 15 pts` | `15 pts` if path traversed within 24 hours; `10 pts` within 48 hours; `5 pts` within 7 days. |
| **5. Transaction Recurrence ($F_{\text{recurrence}}$)** | `0 - 10 pts` | `10 pts` for repeat transactions between suspect and candidate VASP path; `5 pts` for single transfer. |
| **6. Cluster Association ($F_{\text{cluster}}$)** | `0 - 10 pts` | `10 pts` if candidate address shares multi-input co-spending or deposit wallet cluster identity with VASP. |
| **7. Cross-Chain Linkage ($F_{\text{cross\_chain}}$)** | `0 - 10 pts` | `10 pts` if cross-chain bridge event links source asset to target chain deposit address. |
| **8. Ambiguity Penalty ($P_{\text{ambiguity}}$)** | `0 - 25 pts` | `-15 pts` for mixer/privacy pool interactions on path; `-10 pts` for high fan-out intermediary nodes. |

---

## 🎯 3. Classification Boundaries

Based on the final normalized evidence score $S$:

- **$S \ge 85.0$**: **`STRONG_ASSOCIATION`**
- **$65.0 \le S < 85.0$**: **`INFERRED_ASSOCIATION`**
- **$S < 65.0$**: **`UNKNOWN`** (Insufficient evidence for VASP attribution)
